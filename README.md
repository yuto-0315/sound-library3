# 音楽づくり支援アプリ（クラウド対応版）

小学校における音楽づくりの支援教材として開発されたWebアプリケーションです。iPadでの使用を想定して、直感的で使いやすいUIを実現しており、新たにクラウド機能によって複数の児童・生徒間での音声共有が可能になりました。

## 機能概要

### 🎤 音あつめページ
- **大きな録音ボタン**: 押すと録音、もう一度押すと止まる。録音中は経過時間と残りを表示し、止め忘れても 60 秒で自動で止まる
- **録る → 名前をつける**: 止めるとその場で「音に名前をつけよう」が出る。「きく」で確かめ、名前とタグ（候補から選べる）を付けて保存。「録音しなおす」「この音をすてる」（確認あり）
- **ファイルから追加**: 音声ファイルを選んで音素材にできる
- **さいきん集めた音**: 保存した音を新しい順に表示し、▶ で聞ける
- **マイクが使えないとき**: iPad でマイクを許可する手順を案内し、拒否したあとは「ページを読み込み直す」ボタンを出す

### 📚 音ライブラリページ
- **ならべかた**: 新しい順・古い順・名前順・**タグごと**（タグの見出しごとにまとめる）。選んだならべかたは次回も使う
- **探す・絞り込む**: 音の名前やタグで検索（ひらがな／カタカナ、全角／半角を区別しない）、タグで絞り込み
- **音の確認と整理**: 大きな ▶ で聞く、日付と長さの表示、**名前の変更**、タグの追加・削除（ほかの音のタグを候補に出す）、削除（確認あり）
- 集めた音は「音楽づくり」ページの「音素材」から曲に使う

### 🎹 音楽づくりページ (DAW)
- **拍とテンポ**: テンポ（40〜200）・拍子（2/3/4 拍子）を設定。うすい線が 1 拍、こい線と数字が小節
- **拍の頭にくっつく**: 置き方「拍」「半拍」「合わせない」。テンポを変えても、並べた音は同じ拍の上に残る
- **音を置く**: 「音素材」からトラックへドラッグ＆ドロップ。または「＋」ボタンで、選んだトラックの再生位置に置く（続けて押すと順に並ぶ）
- **音の長さが見える**: 音素材の一覧に長さ（秒）、置いた音に実際の音の波形
- **マルチトラック**: トラックの追加・削除・ミュート
- **再生**: 再生・一時停止・停止、上の目盛りを押した所から再生、メトロノーム
- **編集**: 置いた音をタップして「きく」「複製」「削除」、元に戻す・やり直す（⌘Z / Ctrl+Z / Ctrl+Y）、キーボードでも移動できる（← → で拍ごと、↑ ↓ でトラック）
- **ファイル**: ファイルに保存・ファイルを開く・WAV ファイルに書き出す・新しく作る（リセット）・1つ前の作業に戻す
- **自動保存**: 作業内容はこの端末（IndexedDB）に自動で保存され、ページを移動しても消えない
- **先生に送る**: 曲のタイトル・部屋番号・名前・班の番号を付けてサーバーに保存（名前と班は覚えておく）

### 🌐 みんなで共有ページ
- **部屋**: 先生に教えてもらった部屋番号で入る（全角の数字でもよい。次からは自動で入る）。部屋番号は合言葉で、部屋の一覧は生徒には見えない
- **みんなの音**: 試し聞き（もらった数には数えない）、「音ライブラリに入れる」（同じ音を二重に入れない）、名前・タグ・つくった人で検索、タグで絞り込み
- **自動で新しくする**: 30 秒ごとと画面に戻ったときに読み込み直す。新しい音は「新しい音が N こ届きました」を押すと並ぶ（押そうとしたボタンの位置がずれない）
- **自分の音を共有する**: 1. 試し聞きしながら音をえらぶ → 2. 名前とタグをたしかめる → 「みんなに共有する」

### 🏫 先生用管理ページ
- **部屋管理**: 新しい部屋の作成・削除
- **音声ファイル管理**: 生徒が共有した音の一覧・再生・削除
- **楽曲管理**: 生徒が送った楽曲の一覧（班番号つき）と、音楽づくりでの再現
- **暗証番号**: サーバーで設定したときだけ、部屋の作成・削除・一覧、音・楽曲の削除、楽曲の一覧に暗証番号が必要になる。半角の英数字・記号で 6 文字以上。設定していなければ、ページの上に注意を出す（[SETUP.md](SETUP.md)）

## 技術仕様

### フロントエンド
- **フロントエンド**: React 18
- **ルーティング**: React Router DOM
- **スタイリング**: CSS3 (カスタムCSS)
- **音声処理**: Web Audio API, MediaRecorder API
- **データ保存**: IndexedDB（録音した音・音楽づくりの自動保存） + MySQL（クラウド機能）
- **アイコン**: lucide-react

### バックエンド（新規追加）
- **サーバー**: PHP 7.4+
- **データベース**: MySQL 8.0+
- **開発環境**: XAMPP（ローカル開発用）
- **API設計**: RESTful API
- **ファイル管理**: サーバーサイドファイルアップロード

### セキュリティ・制限
- **ファイルサイズ制限**: 共有する音声は 1 ファイル 20MB まで、1 つの部屋で合計 1GB まで
- **対応音声形式**: MP3, WAV, WebM, OGG, M4A（MP4/AAC）, FLAC, CAF（中身から形式を判定し、音声でないファイルは受け付けない）
- **CORS対応**: フロントエンドとAPIの連携
- **入力検証**: SQLインジェクション対策・XSS対策
- **部屋の確認**: 共有された音の一覧・アップロード・楽曲の送信は、部屋の ID と部屋番号の両方を確かめる（`api/room_access.php`）
- **アクセシビリティ**: WCAG 2.1 AAレベル準拠
- **対応ブラウザ**: モダンブラウザ（Chrome, Safari, Firefox, Edge）

## Docker で動かす（別のパソコンで使うとき）

Docker Desktop を入れたパソコンなら、Windows は **`start-docker.bat` をダブルクリックするだけ**で、画面・API・データベースをまとめて起動できます（Mac は `start-docker.command`）。
iPad から録音も使うときは `start-docker-https.bat`。止めるときは `stop-docker.bat`。
手順・設定・データの保存・うまくいかないときは [DOCKER.md](DOCKER.md) を見てください。

## 開発環境のセットアップ

### 必要な環境
- Node.js 16.0以上
- npm 8.0以上

### インストール手順

1. リポジトリのクローン
```bash
git clone <repository-url>
cd sound-library3
```

2. 依存関係のインストール
```bash
npm install
```

3. 開発サーバーの起動
```bash
npm start
```

4. ブラウザで http://localhost:3000 にアクセス

クラウド機能（みんなで共有・クラウド保存・先生用ページ）を試すときは、XAMPP で PHP の API も動かしておきます。
開発サーバーは `/api` へのアクセスを `http://localhost/sound-library3/api` に中継します（`src/setupProxy.js`）。
手順と中継先の変え方は [SETUP.md](SETUP.md) の「5.3 開発サーバーから API を使う」をご覧ください。

## 使用方法

### 音の録音・収集
1. 「音あつめ」ページに移動
2. 大きな「録音開始」ボタンを押して音を録音し、もう一度押して止める
3. 「音に名前をつけよう」で「きく」で確かめ、名前とタグを付けて「保存する」

### 音を見る・整理する
1. 「音ライブラリ」ページに移動
2. ▶ で聞く。「名前」「タグ」で直す。ならべかたを「タグごと」にすると、タグの見出しごとにまとまる

### 音楽づくり
1. 「音楽づくり」ページに移動
2. テンポと拍子を決める
3. 「音素材」から音をトラックにドラッグ＆ドロップ（または「＋」ボタン）。音は拍の頭にくっつく
4. 再生ボタンで作成した音楽を確認し、トラックを増やして音を重ねる
5. できたら「ファイル」から保存・書き出し、または「先生に送る」

### みんなで共有
1. 「みんなで共有」ページで部屋番号を入れる
2. 「自分の音を共有する」で音をえらび、「みんなに共有する」
3. 「みんなの音」で試し聞きし、気に入った音を「音ライブラリに入れる」

## 教育的配慮

- **小学生向けUI**: 大きなボタンと分かりやすいアイコン
- **視覚的フィードバック**: 録音中のアニメーション、ドラッグ時のハイライト
- **直感的操作**: ドラッグ＆ドロップのほか、「＋」ボタンでも音を置ける
- **iPad最適化**: タッチ操作に最適化されたインターフェース（横向き・縦向きのどちらでも 1 画面で使える）
- **アクセシブルデザイン**: 障害のある児童も含めた全ての児童が利用可能
- **多様な学習スタイル**: 視覚・聴覚・運動感覚での学習をサポート

### テスト構成

- **コンポーネントテスト**: App, Navigation, SoundCollection, SoundLibrary, DAWPage, CloudPage, AdminPage
- **データ保存の回帰テスト**: `DAWPage.persistence.test.js`（ページ移動・再読み込みで作業内容が消えないこと など）
- **ユーティリティのテスト**: `src/__tests__/utils/`（音声形式の判定、IndexedDB、プロジェクトの保存形式、拍・テンポの計算、波形、検索の文字そろえ、サーバーの日時）
- **カスタムフックテスト**: useAccessibility, useTouchDrag
- **アクセシビリティテスト**: WAI-ARIA準拠、キーボードナビゲーション
- テスト用の道具は `src/test-utils/` にある（インメモリの IndexedDB、Web Audio のモックなど）

### ブラウザでの E2E テスト（Playwright）

本物の IndexedDB・録音・Web Audio を使って、主要な操作とデータが消えないことを確認します。

```bash
npm run build
npm run start:static
```

別のターミナルで:

```bash
npm run test:e2e
```

- `stability.spec.js`（データが消えない・音楽づくり・音ライブラリ・タッチ操作）と `button-smoke.spec.js`（各ページのボタンを押してもエラーが出ない）を実行します
- 配信先を変えるときは `E2E_BASE_URL`、インストール済みの Chromium を使うときは `E2E_CHROMIUM_PATH` を指定します（`@playwright/test` の版とブラウザの版が違うとき）
- マイクの代わりに 440Hz の音を録音します（録音処理そのものは本物のブラウザで動きます）
